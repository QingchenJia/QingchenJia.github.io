图像分类要解决的问题是：给模型一张图片，让它判断所属类别。本文结合 PyTorch 代码，用 CIFAR-10 数据集训练卷积神经网络。网络先利用相邻像素的关系提取特征，再通过全连接层分类；讲解重点是**数据形状如何变化，以及各层的结构和参数如何确定。**

下面分段展示脚本的各个组成部分。代码中的网络结构和训练设置保持原设定；模型定义中的注释补全了池化的取整规则，其他建议修改会单独标明。

### 一、分类任务与代码组成

#### 1.这份模型要识别什么

CIFAR-10 包含 60,000 张大小为 `32×32` 的彩色图片，分为 50,000 张训练图片和 10,000 张测试图片。数据集共十个类别，每类总计 6,000 张图片。

torchvision 中的类别编号从 0 开始，顺序如下：

| 编号 | 类别               | 编号 | 类别          |
| ---- | ------------------ | ---- | ------------- |
| 0    | airplane（飞机）   | 5    | dog（狗）     |
| 1    | automobile（汽车） | 6    | frog（青蛙）  |
| 2    | bird（鸟）         | 7    | horse（马）   |
| 3    | cat（猫）          | 8    | ship（船）    |
| 4    | deer（鹿）         | 9    | truck（卡车） |

模型对每张图片输出十个分数。分数最大的位置就是预测的类别编号，例如位置 `3` 对应猫。实际使用时也可以通过 `test_data.classes` 读取类别名称。

这是监督学习中的多分类任务。训练图片是输入，数据集已有的类别编号是标签；标签用于指导训练和核对预测结果，不会作为图片输入模型。

#### 2.导入模块，选择计算设备

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import time
from torchsummary import summary
import os

device = torch.device("cuda:0") if torch.cuda.is_available() else torch.device("cpu")
path_prefix = "Image-Classification/"
model_path = path_prefix + "model/"
```

`torch` 负责张量运算与自动求导，`nn` 提供网络层，`optim` 提供优化器。`datasets` 和 `transforms` 加载、转换图片，`DataLoader` 组织样本；`summary` 展示模型概要，`time` 和 `os` 分别用于计时与目录操作。

`cuda:0` 表示第一张可用的 CUDA 显卡。CUDA 不可用时使用 CPU；这段代码没有自动选择其他 GPU 后端。训练时，模型、图片和标签需要放到同一计算设备上。

`path_prefix` 是数据与模型文件的公共路径前缀，相对于程序当前工作目录。`model_path` 在它后面拼接 `model/`，用于保存和读取训练得到的权重。

### 二、创建数据集，理解输入张量

#### 1.下载并读取CIFAR-10

```python
def create_dataset():
    # 下载并加载 CIFAR-10 数据集
    train_data = datasets.CIFAR10(
        root=path_prefix + "/data",
        train=True,
        download=True,
        transform=transforms.ToTensor(),
    )
    test_data = datasets.CIFAR10(
        root=path_prefix + "/data",
        train=False,
        download=True,
        transform=transforms.ToTensor(),
    )
    return train_data, test_data
```

`train=True` 与 `train=False` 分别读取官方训练集、测试集，`download=True` 会检查并复用完整的本地数据。函数返回两个数据集对象，训练与评估代码分别用 `_` 忽略其中一个返回值。

`path_prefix` 自带结尾斜杠，拼接 `"/data"` 会出现双斜杠；这里通常仍可作为本地路径使用，也可改写为 `os.path.join(path_prefix, "data")`。

#### 2.ToTensor改变了什么

RGB 图片包含三个颜色通道，每个通道是一张 `32×32` 数值矩阵。对于这里的 8 位图片，`ToTensor()` 将图片转换为 `[3, 32, 32]` 的通道在前浮点张量，同时将像素从 `0～255` 缩放到 `0～1`。

这一步没有进行通道标准化、随机裁剪或翻转。

#### 3.一张图片与一批图片的size

PyTorch 的二维卷积通常接收 `[N, C, H, W]` 格式的批量输入：

| 维度                | 含义               | 本例中的取值                |
| ------------------- | ------------------ | --------------------------- |
| `N`，正文也记为 `B` | 当前批次的图片数量 | 通常为 64，最后一批可能较少 |
| `C`                 | 通道数量           | RGB 图片为 3                |
| `H`                 | 高度               | 32                          |
| `W`                 | 宽度               | 32                          |

因此，一批 64 张图片的形状是 `[64, 3, 32, 32]`，对应标签形状是 `[64]`。严格来说，这一批输入是四维张量，不是单个二维矩阵；我们讨论卷积后的“矩阵大小”时，通常指每个通道的高和宽。

一张图片包含 `3×32×32=3072` 个输入数值。**3072 是数值个数，3 是通道数，两者含义不同。** 原网络没有一开始就把这 3072 个数展平，而是先保留空间结构做卷积。

### 三、通过示意图理解输入层、隐藏层和输出层

#### 1.网络的完整结构

![batch_size为1时，单张RGB图像经过两轮卷积池化、展平和全连接层的张量维度变化](../深度学习图像分类实践/cnn-architecture.png)

图中以 `batch_size=1` 为例，从左到右展示一张 RGB 图片的完整分类过程。输入形状为 `[1, 3, 32, 32]`，依次经过两组卷积、ReLU 和池化后，得到 `[1, 16, 6, 6]`；再展平为 `[1, 576]`，经过两个全连接隐藏层变为 `[1, 512]` 和 `[1, 64]`，最后输出 `[1, 10]`，即这张图片的十个类别分数。

卷积与池化阶段的形状采用 `[样本数, 通道数, 高度, 宽度]`；展平后的形状采用 `[样本数, 特征数]`。图中的叠片用于表达多通道结构，具体数量与尺寸以文字标注为准；图片纹理和节点均为示意，不是模型实际计算得到的特征或预测结果。后文用 `B` 表示一般情况下的输入图片数量。

可以将整个网络划分为三部分：

| 部分     | 对应结构                                   | 作用                                  |
| -------- | ------------------------------------------ | ------------------------------------- |
| 输入层   | `[B, 3, 32, 32]` 图片张量                  | 提供 RGB 像素，没有需要训练的输入权重 |
| 隐藏部分 | 两组卷积、ReLU、池化，以及两个全连接隐藏层 | 从像素计算中间特征，再组合分类依据    |
| 输出层   | `Linear(64, 10)`                           | 给出十个类别的原始分数                |

这里有五个带可训练参数的层：两个卷积层和三个全连接层。其中最后一个全连接层是输出层，其余四个是带参数的隐藏层。ReLU、池化和展平也属于中间计算，但不增加可训练参数。

#### 2.定义卷积和全连接层

```python
class image_model(nn.Module):
    def __init__(self):
        super(image_model, self).__init__()

        self.conv1 = nn.Conv2d(
            in_channels=3, out_channels=6, kernel_size=3, stride=1, padding=0
        )
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
        # 空间尺寸：32 -> 30 -> 15

        self.conv2 = nn.Conv2d(
            in_channels=6, out_channels=16, kernel_size=3, stride=1, padding=0
        )
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
        # 空间尺寸：15 -> 13 -> 6；池化按默认规则向下取整

        self.linear1 = nn.Linear(16 * 6 * 6, 512)
        self.linear2 = nn.Linear(512, 64)
        self.linear3 = nn.Linear(64, 10)

    def forward(self, x):
        x = self.pool1(torch.relu(self.conv1(x)))
        x = self.pool2(torch.relu(self.conv2(x)))
        x = x.reshape(x.size(0), -1)
        x = torch.relu(self.linear1(x))
        x = torch.relu(self.linear2(x))
        x = self.linear3(x)
        return x
```

`nn.Module` 负责登记和管理各层参数。`__init__()` 定义网络层，`forward()` 定义计算顺序；调用 `model(features)` 时，PyTorch 按该顺序执行前向传播。

#### 3.卷积隐藏层的通道怎样设置

`conv1` 的 `in_channels=3` 必须与 RGB 输入匹配；`out_channels=6` 表示生成六张特征图。默认 `groups=1` 时，一个输出通道会同时使用全部三个输入通道，其卷积核权重形状为 `[3, 3, 3]`：第一个 3 是输入通道数，后两个 3 是卷积窗口的高和宽。

在一个输出位置上，这个卷积核分别处理三个输入通道的局部区域，将结果求和，再加上该输出通道的偏置。共有六组这样的卷积核，所以 `conv1.weight` 的形状是 `[6, 3, 3, 3]`。

同一组权重会在图片的不同空间位置重复使用，这叫权重共享。它让卷积层能够用较少参数扫描不同位置的局部模式。

`conv2` 接收第一组池化输出的六个通道，因此 `in_channels=6`。它输出十六个通道，对应权重形状 `[16, 6, 3, 3]`。这十六个通道不是十六种类别，而是十六组学到的中间特征。

#### 4.全连接隐藏层为什么是512和64

![全连接部分的输入特征、512与64个隐藏单元以及10个输出单元](../深度学习图像分类实践/dense-hidden-layers.png)

图中的圆点只是代表性节点，省略号表示未画出的节点；相邻两列在实际网络中是全连接的。左侧 576 个节点是卷积部分展平后的特征，不是原始图片输入层。

| 设置                    | 如何确定                   | 修改时需要注意什么                     |
| ----------------------- | -------------------------- | -------------------------------------- |
| `576` 个输入特征        | 由 `16×6×6` 推导得到       | 卷积、池化或图片尺寸变化后要重新计算   |
| 第一隐藏层 `512` 个单元 | 人工选择的网络宽度         | 改成其他值时，要同步修改下一层输入维度 |
| 第二隐藏层 `64` 个单元  | 人工选择的网络宽度         | 要与输出层的 `in_features` 一致        |
| 输出层 `10` 个单元      | 由 CIFAR-10 的十个类别决定 | 更换分类任务时与类别数匹配             |

**512 和 64 是超参数，不是由图片大小唯一算出来的答案。** 它们控制全连接部分的表示能力和参数数量。更宽的层通常增加参数、计算量与过拟合风险，并不保证测试准确率更高。

例如，将第一隐藏层宽度改为 256 时，应同时改成 `Linear(576, 256)` 和 `Linear(256, 64)`。这属于新的网络配置，需要重新训练；原有 512 宽度的权重不能直接完整加载到新结构。

#### 5.ReLU与输出分数

ReLU 按 `max(0, x)` 计算：保留正数，将负数置零，不改变张量形状。它用于两层卷积和前两个全连接层之后，使网络能够表达非线性关系。

最后的 `linear3` 不接 ReLU，也不接 Softmax，直接输出 logits，也就是未经概率归一化的类别分数。分数可以为负，十个分数也不需要相加等于 1。

### 四、逐步计算卷积和池化后的矩阵size

#### 1.先记住通用计算公式

对单个空间方向，高度或宽度的计算形式相同。卷积层以及采用默认 `ceil_mode=False` 的最大池化层，使用以下输出尺寸公式：

$$
L_{\mathrm{out}}=\left\lfloor\frac{L_{\mathrm{in}}+2P-D(K-1)-1}{S}\right\rfloor+1
$$

| 符号            | 含义                           | 本例中的值         |
| --------------- | ------------------------------ | ------------------ |
| `L_in`、`L_out` | 输入、输出的高度或宽度         | 逐层变化           |
| `K`             | 窗口大小，即 `kernel_size`     | 卷积为 3，池化为 2 |
| `S`             | 步幅，即 `stride`              | 卷积为 1，池化为 2 |
| `P`             | 两侧各补多少位置，即 `padding` | 都为 0             |
| `D`             | 膨胀率，即 `dilation`          | 都使用默认值 1     |
| 向下取整符号    | 取不大于结果的最大整数         | 例如 5.5 取为 5    |

`D=1` 表示窗口中的采样位置连续相邻。将它代入后，公式可以简化为：

$$
L_{\mathrm{out}}=\left\lfloor\frac{L_{\mathrm{in}}+2P-K}{S}\right\rfloor+1
$$

公式计算的是窗口可以放置多少次。高度和宽度应分别计算；这里输入和窗口都是正方形，两次计算结果相同。批大小不参与这个公式，卷积输出通道由 `out_channels` 指定，普通最大池化不改变通道数。

#### 2.第一次卷积：32变成30

`conv1` 使用 `3×3` 窗口、步幅 1、不补边：

$$
H_1=W_1=\left\lfloor\frac{32+2\times0-3}{1}\right\rfloor+1=30
$$

张量形状从 `[B, 3, 32, 32]` 变成 `[B, 6, 30, 30]`。由于没有 padding，窗口必须完整落在输入内，每个方向的起点为 `0～29`，共 30 个位置；随后执行 ReLU，形状不变。

#### 3.第一次池化：30变成15

`pool1` 使用 `2×2` 窗口、步幅 2：

$$
H_2=W_2=\left\lfloor\frac{30+2\times0-2}{2}\right\rfloor+1=15
$$

每个通道独立处理，每个窗口选取一个最大值，因此输出为 `[B, 6, 15, 15]`。池化没有可训练权重，也不会将六个通道合并。

![最大池化的数值示例与13乘13输入的边界处理](../深度学习图像分类实践/maxpool-size.png)

图左是一个独立的数值示例：`4×4` 矩阵经过窗口为 2、步幅为 2 的最大池化后，得到 `2×2` 矩阵。四个窗口的最大值分别为 6、8、9、7，池化保留的是局部最大响应，不是局部平均值。

#### 4.第二次卷积：15变成13

`conv2` 仍使用 `3×3` 窗口、步幅 1、不补边，但输入通道变为 6，输出通道设为 16：

$$
H_3=W_3=\left\lfloor\frac{15+2\times0-3}{1}\right\rfloor+1=13
$$

输出形状是 `[B, 16, 13, 13]`。后续 ReLU 只改变数值，形状不变。

#### 5.第二次池化：13为什么变成6

`pool2` 的窗口为 `2×2`，步幅为 2，默认向下取整：

$$
H_4=W_4=\left\lfloor\frac{13+2\times0-2}{2}\right\rfloor+1
=\lfloor5.5\rfloor+1=6
$$

原注释直接写 `(13 - 2) / 2 + 1 = 6`，省略了向下取整。从普通除法看，左边等于 6.5；得到整数 6 的关键是池化层的取整规则。

在 `13×13` 的特征图上，每个方向的窗口起点是 `0, 2, 4, 6, 8, 10`，共六个。起点 10 的窗口覆盖索引 10 和 11；起点 12 的窗口会越界，所以默认不再产生输出。

图右用红色标出了最后一行和最后一列：在本例无填充、向下取整的设置下，它们不参与任何完整池化窗口。这些位置指的是当前 `13×13` 特征图，并不是直接删除原图的一行和一列像素。

#### 6.展平：16张6×6特征图变成576个数

经过第二次池化，每张图片还剩十六个通道，每个通道包含 36 个数：

$$
F=16\times6\times6=576
$$

`x.reshape(x.size(0), -1)` 保留第一维，让 PyTorch 推断展平后的特征数，将 `[B, 16, 6, 6]` 变为 `[B, 576]`。展平不增加特征、不合并样本，也没有可训练参数。

不能在这里写死 `reshape(64, -1)`。当实际输入图片数量变化时，固定第一维会导致形状不匹配或破坏样本维度；使用 `x.size(0)` 才能保留每张图片与其特征的对应关系。

#### 7.把全部尺寸放在一起核对

| 步骤             | 配置或计算                   | 输出形状          | 每张图片的数值个数 |
| ---------------- | ---------------------------- | ----------------- | ------------------ |
| 输入             | RGB，`32×32`                 | `[B, 3, 32, 32]`  | 3072               |
| `conv1` + ReLU   | `3→6` 通道，`K=3, S=1, P=0`  | `[B, 6, 30, 30]`  | 5400               |
| `pool1`          | `K=2, S=2`                   | `[B, 6, 15, 15]`  | 1350               |
| `conv2` + ReLU   | `6→16` 通道，`K=3, S=1, P=0` | `[B, 16, 13, 13]` | 2704               |
| `pool2`          | `K=2, S=2`，向下取整         | `[B, 16, 6, 6]`   | 576                |
| `reshape`        | 保留批维，展平特征           | `[B, 576]`        | 576                |
| `linear1` + ReLU | `576→512`                    | `[B, 512]`        | 512                |
| `linear2` + ReLU | `512→64`                     | `[B, 64]`         | 64                 |
| `linear3`        | `64→10`                      | `[B, 10]`         | 10                 |

空间尺寸变小，并不意味着数值总量一定减少。例如第一次卷积后，通道数翻倍，单张图片的中间数值由 3072 个增加到 5400 个。判断内存和计算规模时，应同时考虑批大小、通道数、高度和宽度。

### 五、结合模型概要截图计算参数量

#### 1.读取截图中的三列

![模型参数概要：各层输出形状以及329954个可训练参数](../深度学习图像分类实践/model-parameters.png)

截图三列依次表示模块类型与执行编号、输出形状、参数数量。概要按单张图片显示，所以第一层卷积输出为 `[1, 6, 30, 30]`。`Conv2d-1` 中的编号由工具生成，不是卷积核数量。

#### 2.卷积层的参数为什么只有168和880

本例 `groups=1`，且 `bias=True` 使用默认设置。卷积层参数量为：

$$
P_{\mathrm{conv}}=C_{\mathrm{out}}\left(C_{\mathrm{in}}K_HK_W+1\right)
$$

括号里的前半部分是一个输出通道的卷积核权重数，`+1` 是该输出通道的偏置。不同空间位置共享这些权重，因此公式不需要乘输出特征图的高和宽，也不需要乘批大小。

第一层有六个输出通道，每个输出通道有 `3×3×3=27` 个权重和一个偏置：

$$
P_{\mathrm{conv1}}=6(3\times3\times3+1)=168
$$

第二层有十六个输出通道，每个输出通道有 `6×3×3=54` 个权重和一个偏置：

$$
P_{\mathrm{conv2}}=16(6\times3\times3+1)=880
$$

这里要区分“激活值数量”和“参数数量”：`conv1` 对一张图片输出 5400 个数，但只用 168 个可训练参数。前者随输入变化，后者是网络在训练中学习的权重和偏置。

#### 3.全连接层的参数怎样计算

一个 `Linear(I, O)` 层包含形状为 `[O, I]` 的权重和 `O` 个偏置：

$$
P_{\mathrm{linear}}=I\times O+O
$$

| 层        | 权重形状     | 参数计算      | 参数数量 |
| --------- | ------------ | ------------- | -------- |
| `linear1` | `[512, 576]` | `576×512+512` | 295,424  |
| `linear2` | `[64, 512]`  | `512×64+64`   | 32,832   |
| `linear3` | `[10, 64]`   | `64×10+10`    | 650      |

加上两个卷积层，得到：

$$
P_{\mathrm{total}}=168+880+295424+32832+650=329954
$$

第一全连接层就占总参数量约 89.5%，因此调整这个隐藏层的宽度会明显影响模型大小。两层池化没有权重和偏置，参数量均为 0。

#### 4.截图为什么没有ReLU和展平

`torch.relu(...)` 和 `reshape(...)` 没有登记为独立的 `nn.Module`，因此依赖模块前向钩子的 torchsummary 不会单列它们。应结合 `forward()` 阅读概要表，不能据此认为网络没有激活或展平操作。

截图中的全部 329,954 个参数默认都允许计算梯度，所以可训练参数量与总参数量相同。“不可训练参数为 0”也不表示网络里不存在无参数操作。

#### 5.概要中的内存估算如何理解

按 float32 每个参数占 4 字节计算，权重与偏置共占 `329954×4÷1024²≈1.26 MiB`。截图虽标作 `MB`，实际采用的是 `1024²` 字节单位。

`Estimated Total Size` 是基于概要显示输入和层输出的估算，不是训练显存实测值；训练还需要梯度、Adam 状态、缓存和算子工作空间等内存。

### 六、模型怎样完成训练

#### 1.训练函数

```python
def train_model():
    # 创建数据集和数据加载器
    train_data, _ = create_dataset()
    train_loader = DataLoader(train_data, batch_size=64, shuffle=True)

    # 创建模型、损失函数和优化器
    model = image_model().to(device)
    criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=0.0001)

    epochs = 50
    model.train()

    for epoch in range(epochs):
        total_loss, sample_num, start_time = 0.0, 0, time.time()

        for features, labels in train_loader:
            features, labels = features.to(device), labels.to(device)

            pred = model(features)
            loss = criterion(pred, labels)

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

            total_loss += loss.item() * len(labels)
            sample_num += len(labels)

        print(
            f"Epoch [{epoch + 1}/{epochs}]\tLoss: {total_loss / sample_num:.4f}, Time: {time.time() - start_time:.2f}s"
        )

    os.makedirs(model_path, exist_ok=True)
    torch.save(model.state_dict(), model_path + "image_model.pth")
```

#### 2.训练过程中哪些参数会改变

`model = image_model().to(device)` 创建网络并将参数放到指定设备，`model(features)` 按照 `forward()` 中定义的顺序计算类别分数。

`model.parameters()` 将卷积层与全连接层的权重、偏置交给优化器，`optimizer.step()` 执行参数更新。训练改变的是这些数值，不会自动改变卷积通道数，也不会把 512 个隐藏单元变成其他数量。

#### 3.训练模式和权重保存

`model.train()` 设置训练模式。当前网络没有 Dropout 和 BatchNorm，训练与评估模式不会改变这些卷积、池化、全连接层和 ReLU 的计算规则，但仍应保留规范的模式切换。

`os.makedirs(model_path, exist_ok=True)` 在目录不存在时创建目录。`torch.save(model.state_dict(), ...)` 保存各层权重与偏置，不会保存 Python 模型类定义，也不会保存本次 Adam 状态和训练轮数。

保存发生在训练循环结束后，因此文件保存的是最终模型，不是经验证集挑选出的最佳模型。再次运行训练会从新初始化的网络开始，并在完成时覆盖同一路径下的 `image_model.pth`。

### 七、加载权重并计算测试准确率

#### 1.评估函数

```python
def evaluate_model():
    _, test_data = create_dataset()
    test_loader = DataLoader(test_data, batch_size=64, shuffle=False)

    model = image_model().to(device)
    model.load_state_dict(torch.load(model_path + "image_model.pth"))
    model.eval()

    correct, total = 0, 0

    with torch.no_grad():
        for features, labels in test_loader:
            features, labels = features.to(device), labels.to(device)

            pred = model(features)
            pred = torch.argmax(pred, dim=1)

            correct += (pred == labels).sum()
            total += len(labels)

    print(f"Test Accuracy: {correct / total * 100:.4f}%")
```

先建立相同结构的模型，再加载 `state_dict`，新模型的初始随机参数才会被训练结果替换。层名称和参数形状都需要与保存时对应；仅仅保证最后输出十类还不够。

#### 2.argmax为什么沿dim=1计算

输出的第 0 维是图片，第 1 维是十个类别。`argmax(pred, dim=1)` 对每张图片选出最高分的位置，将 `[B, 10]` 转换成 `[B]`。

例如，假设一张图片的十个分数为 `[-0.4, 0.2, 0.1, 2.8, -0.5, 1.3, 0.0, -0.2, 0.4, 0.6]`，最大分数 2.8 位于索引 3，因此预测类别为 cat。这只是索引示例，不是实际预测结果。

Softmax 不改变最大项的位置，因此获取类别编号时不需要先计算概率。

### 八、模型概要与运行顺序

#### 1.模型概要函数

```python
def model_summary():
    model = image_model().to(device)
    summary(model, (3, 32, 32), batch_size=1)
```

`(3, 32, 32)` 表示单张图片的通道、高度和宽度，不包含批维。`batch_size=1` 是概要显示与内存估算使用的批大小，不会修改训练加载器中的 `batch_size=64`。

torchsummary 会构造模拟输入并执行前向计算来收集输出信息，不会下载数据，也不会训练模型。以 1.5.1 的实现为例，其内部模拟输入使用两条样本，输出表格中的批维再按 `batch_size` 参数展示，所以不能把截图直接理解成真实训练批次的运行记录。

概要函数与训练函数分别创建模型，二者结构相同，参数不会相互继承。若要明确指定概要输入设备，可在 `summary(...)` 中增加 `device=device.type`；1.5.1 接受 `"cpu"` 或 `"cuda"` 字符串。

#### 2.主入口的执行顺序

```python
if __name__ == "__main__":
    model_summary()
    train_model()
    evaluate_model()
```

1. 创建临时模型，输出各层形状与参数概要。
2. 加载训练数据，创建新的模型，完成训练并保存参数。
3. 创建同结构模型，读取刚保存的参数，在测试集上统计准确率。

程序会先显示模型概要，再完成训练与评估。分类效果需要根据实际测试结果判断，模型参数截图本身不能证明识别准确率。
