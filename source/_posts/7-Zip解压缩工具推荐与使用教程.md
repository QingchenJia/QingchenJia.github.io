### 一、为什么推荐7-Zip

下载学习资料、接收同事发来的文件、整理一批照片，都会遇到压缩包。Windows 自带的解压功能已经能处理不少情况，但遇到加密文件、分卷压缩包，或者需要自己设置压缩参数时，专门的工具会更顺手。

[7-Zip](https://7-zip.org/) 是一款免费、开源的文件压缩与解压工具。界面比较朴素，常用功能集中在右键菜单和文件管理器中，适合长期作为 Windows 的日常工具使用。

我推荐它的原因很直接：**安装包小、没有广告、常见格式支持广，而且不需要注册账号或购买会员。** 平时只用右键菜单，就能完成大部分压缩和解压操作。

官方明确说明，个人和商业组织的电脑都可以免费使用 7-Zip。如果只是安装软件来处理文件，不需要为此支付授权费用。

### 二、它能处理哪些文件

#### 1.软件名称和压缩格式不是一回事

7-Zip 是软件名称，`.7z` 是一种压缩包格式。安装 7-Zip 后，既能处理 `.7z`，也能处理 `.zip`、`.rar` 等常见文件，并不是只能打开与自己名字相似的格式。

压缩可以理解为把一批文件装进一个包，并尽量减少体积；解压则是把包里的文件取出来，恢复成可以直接使用的文件和文件夹。

| 格式            | 7-Zip的常见用途          | 日常理解                                  |
| --------------- | ------------------------ | ----------------------------------------- |
| 7z              | 创建与解压               | 适合资料归档、加密和追求较小体积          |
| ZIP             | 创建与解压               | 通用性好，适合向别人发送文件              |
| RAR             | 解压                     | 能打开常见 RAR、RAR5 压缩包，不能创建 RAR |
| TAR             | 打包与解包               | 常见于开发资料，本身通常不负责压缩体积    |
| GZIP、XZ、BZIP2 | 压缩与解压               | 常与 TAR 配合使用                         |
| ISO、CAB、MSI等 | 读取或提取其中支持的内容 | 不能据此认为能创建镜像或完成软件安装      |

**支持解压某种格式，不等于支持生成这种格式。** 如果对方明确要求提交 `.rar`，不能把 `.7z` 文件直接改名来代替。

#### 2.哪些地方比基础解压更方便

- 给一批文件设置密码，必要时连文件名也一起隐藏。
- 把较大的压缩包拆成多个分卷，方便分批传输。
- 在解压前查看文件列表，或只提取其中几个文件。
- 测试压缩包是否完整，排查下载或传输问题。
- 使用命令行重复执行压缩、解压和检查任务。

如果只是偶尔打开普通 ZIP，系统自带功能也很方便；如果经常收发不同格式的资料，7-Zip 可以把这些操作集中起来。

### 三、从官网下载安装

#### 1.选择对应的Windows版本

打开 [7-Zip 官网](https://7-zip.org/)，或进入 [官方下载页面](https://7-zip.org/download.html)，找到 Windows 安装程序。

普通用户优先选择 `.exe` 安装包。官网也推荐使用 EXE 安装程序；页面中的源码、SDK 和 Extra 软件包主要面向开发或特定用途，不是首次安装的首选。

| 电脑类型                                           | 建议下载的版本 |
| -------------------------------------------------- | -------------- |
| 大多数使用 Intel、AMD 处理器的 Windows 电脑        | 64-bit x64     |
| 使用 ARM 处理器的 Windows 电脑，例如部分骁龙笔记本 | 64-bit ARM64   |
| 仍在使用 32 位 Windows 的旧电脑                    | 32-bit x86     |

不确定时，打开 Windows“设置 → 系统 → 系统信息”，查看“系统类型”。不同系统版本的入口名称可能略有差异，也可以直接在设置中搜索“系统类型”。

这里应同时看操作系统位数和处理器架构。不是所有“64 位电脑”都应该下载 x64，ARM64 电脑应优先使用对应的 ARM64 安装程序。

#### 2.完成安装

1. 下载与电脑匹配的官方 EXE 安装程序。
2. 双击运行，按 Windows 提示确认安装权限。
3. 保留默认目录，或选择自己方便管理的位置。
4. 点击 `Install`，等待安装结束后关闭窗口。
5. 从开始菜单打开 `7-Zip File Manager`。

常见的默认安装位置是：

```text
C:\Program Files\7-Zip\
```

日常压缩和解压自己的文件，不需要一直以管理员身份运行。安装和修改部分系统级设置时，才可能需要相应权限。

### 四、第一次使用的简单设置

#### 1.切换中文界面

如果启动后显示英文，可以进入 `Tools → Options → Language`，选择简体中文并应用。

切换后，主要设置入口是“工具 → 选项”。中文翻译可能随版本调整，遇到名称略有不同的选项，结合所在页面判断即可。

#### 2.检查右键菜单

选中一个压缩包并点击鼠标右键，查看是否有“7-Zip”菜单。

Windows 11 默认使用较简洁的右键菜单，如果第一层没有看到，可以点击“显示更多选项”，再寻找 7-Zip。

需要调整菜单项目时，打开“工具 → 选项 → 7-Zip”，检查外壳集成相关设置，并按习惯保留常用入口，例如：

- 打开压缩包。
- 提取文件。
- 提取到当前文件夹。
- 提取到以压缩包命名的文件夹。
- 添加到压缩包。

中文界面中常用“提取”表示“解压”。如果调整后暂时没有变化，先重新打开右键菜单，再按需要重启文件资源管理器。

#### 3.按需设置默认打开方式

如果希望双击 `.7z` 时直接打开 7-Zip，可以在 Windows“设置 → 应用 → 默认应用”中，按文件扩展名选择 7-Zip。

也可以在文件的“打开方式”中选择 `7-Zip File Manager`，按系统提示设置默认应用。无需把所有支持的文件类型一次性全部关联。

建议先处理 `.7z`、`.zip`、`.rar` 这几种常用格式。ISO 等文件可能已经有合适的系统默认操作，可以保留原来的习惯。

### 五、日常解压：记住这几个入口

#### 1.优先提取到独立文件夹

假设下载了一个 `学习资料.zip`，里面可能有很多文档，也可能已经套了一层文件夹。

不确定内部结构时，可以先打开压缩包看一眼，再选择提取位置。日常最省事的方式，是通过右键菜单提取到以压缩包命名的文件夹。

1. 在资源管理器中选中 `学习资料.zip`。
2. 右键进入“7-Zip”，Windows 11 必要时先点“显示更多选项”。
3. 选择提取到“学习资料”文件夹的菜单项。
4. 等待进度结束，进入新建文件夹查看内容。

这样即使压缩包里有几十个散文件，也会集中放在同一个目录中，后续移动、整理都方便。

#### 2.三个解压入口怎么选

| 入口             | 文件会放在哪里           | 适用情况                           |
| ---------------- | ------------------------ | ---------------------------------- |
| 提取文件         | 弹出窗口，由自己指定目录 | 想解压到其他磁盘或固定资料目录     |
| 提取到当前文件夹 | 直接放到压缩包所在目录   | 已确认内部结构，当前目录也足够整洁 |
| 提取到单独文件夹 | 放到以压缩包命名的目录   | 大多数日常下载场景                 |

遇到同名文件提示时，先确认是否需要覆盖。对于不同版本的资料，提取到一个新的空文件夹，通常更容易比较内容。

#### 3.只取出其中几个文件

用 7-Zip 打开压缩包，选中需要的文件或文件夹，点击工具栏中的“提取”，指定保存位置即可。

处理大型压缩包时，建议明确指定提取目录。官方 FAQ 说明，从 7-Zip 拖拽文件到资源管理器时，会先使用临时目录，再复制到目标位置，可能额外占用系统盘空间。

需要编辑文档或运行带有多个配套文件的软件时，先完整解压到普通文件夹。这样保存位置更清楚，也能避免遗漏程序需要的文件。

### 六、自己创建压缩包

#### 1.把一个文件夹打包发给别人

下面以 `项目资料` 文件夹为例：

1. 整理好文件，关闭仍在修改的文档。
2. 右键点击 `项目资料`，选择“7-Zip → 添加到压缩包”。
3. 将压缩包名称设置为 `项目资料.zip`。
4. 将“压缩格式”设为 `zip`，压缩方法使用 `Deflate`。
5. 压缩等级先选“标准”，其他参数保持默认。
6. 点击确定，完成后打开压缩包检查文件列表。

如果要把多个文件合成一个包，先同时选中这些文件，再执行相同操作即可。

#### 2.ZIP与7z应该怎么选

| 需求                                   | 推荐设置                  | 原因                             |
| -------------------------------------- | ------------------------- | -------------------------------- |
| 发给同事、同学，不清楚对方使用什么工具 | ZIP，Deflate，先不加密    | 常见系统和工具通常都能处理       |
| 自己归档文档、代码等资料               | 7z，LZMA2                 | 对不少可压缩内容有较好的体积表现 |
| 希望密码同时保护文件名                 | 7z，设置密码并加密文件名  | 可以隐藏压缩包内部的名称列表     |
| 只是把视频、照片集中成一个文件         | ZIP或7z，较快等级或仅存储 | 这类文件通常已经压缩过           |

7z 不保证每次都比 ZIP 小。实际效果与文件内容、压缩方法和参数有关，可以用一小批自己的资料比较后再决定。

ZIP 的兼容性也取决于压缩和加密方式。上面推荐的普通 ZIP 与加密 ZIP，不能视为完全相同的兼容性水平。

#### 3.不用一开始就选择最高压缩等级

压缩等级越高，通常越耗时，也可能需要更多内存，但体积减少未必明显。

可以先按下面的习惯使用：

- 临时发送资料：选择“标准”，兼顾速度和体积。
- 文件很多、只想快点打包：选择较快等级。
- 长期归档，而且愿意等待：尝试较高等级，再比较结果。
- 视频、JPEG 图片、已有压缩包：不要期待再压缩后大幅缩小。

“仅存储”表示把文件装进一个包，不主动压缩内容。对于已经压缩得很充分的文件，它仍然有方便传输和整理的价值。

字典大小、线程数等参数先保持默认即可。如果电脑内存不多，关注窗口中的内存用量估计，不要为了更小的压缩包盲目提高参数。

### 七、为压缩包设置密码

#### 1.推荐使用7z加密

需要给合同、个人资料等文件加密时，可以在“添加到压缩包”窗口中完成：

1. 将“压缩格式”选择为 `7z`。
2. 在“加密”区域输入密码，并再次确认。
3. 确认加密方法为 `AES-256`。
4. 如果不希望别人看到内部文件名，勾选“加密文件名”。
5. 创建后关闭窗口，再重新打开压缩包，检查密码提示。

建议使用较长、难以猜到的密码，并妥善保存。7-Zip 不提供账号找回密码功能，遗忘密码可能导致自己也无法取出文件。

“加密文件名”隐藏的是压缩包内部的文件名称，压缩包自身的名称仍能看到。因此，外层文件名也尽量不要直接写入敏感信息。

#### 2.给别人发送前确认能否解压

7-Zip 支持在 ZIP 中使用 AES-256 加密，但部分系统内置解压工具或旧软件不支持这种加密方式。

如果对方提示无法解压，可以请对方使用支持相应加密方式的工具。不要因为普通 ZIP 能打开，就认为所有带密码的 ZIP 都能直接打开。

ZIP 中另一种常见方式 `ZipCrypto` 兼容范围较广，但保护强度较弱，不建议用它承载敏感资料。

发送加密文件时，可以把压缩包和密码通过不同渠道交付。创建加密包不会自动删除原文件，电脑上的明文副本仍需按自己的资料管理方式处理。

### 八、文件太大时使用分卷压缩

#### 1.把大文件拆成几个小包

有些平台限制单个上传文件大小。遇到这种情况，可以让 7-Zip 在创建压缩包时，同时把输出拆成多个分卷。

1. 选中文件或文件夹，进入“添加到压缩包”。
2. 选择 `7z` 格式，并填写压缩包名称。
3. 找到“分卷大小，字节”输入框。
4. 例如填写 `100M`，将每卷上限设为约 100 MiB。
5. 点击确定，等待全部分卷生成。

生成的文件通常类似：

```text
项目资料.7z.001
项目资料.7z.002
项目资料.7z.003
```

最后一个分卷可以更小。7-Zip 的 `M` 按 1024 的倍数计算，与一些平台使用的十进制 MB 不完全一样；如果上传上限写着 100 MB，可填写 `90M`，留出余量。

#### 2.解压时从第一个分卷开始

接收方先下载全部分卷，放在同一个文件夹中，保留原有名称，再用 7-Zip 打开或提取 `.001`。

不用分别解压每个分卷，也不要随意把 `.002` 改成 `.7z`。这些文件共同组成一个压缩包，缺少中间一卷就可能无法完整提取内容。

RAR 分卷的名称可能是 `part1.rar`、`part2.rar` 等，通常从第一卷开始处理；分卷命名不同，不要机械地只寻找 `.001`。

### 九、几个容易忽略的实用功能

#### 1.测试压缩包是否完整

用 7-Zip 打开压缩包，点击工具栏中的“测试”，可以检查读取和解压校验是否报错，而不把文件提取到目标文件夹。

这适合用在大文件下载完成后，或者重要资料打包完成后。加密包测试时可能需要输入密码，分卷包则需要准备全部分卷。

测试通过说明本次读取和校验未发现问题，不代表里面的程序一定安全，也不能证明打包时没有漏选文件。

#### 2.查看SHA-256校验值

当下载页面提供 SHA-256 时，可以在资源管理器右键菜单的“CRC SHA”中选择对应算法，计算下载文件的校验值；该入口是否显示取决于菜单设置。

将结果与发布者提供的值完整比较。一致表示文件内容与该校验值对应，前提是校验值本身来自可信的发布渠道。

它也适合检查文件传输前后是否变化。校验值不是密码，也不能用来解密压缩包。

#### 3.认识固实压缩

7z 的固实压缩可以把多个文件放在一起压缩。对于内容相近的大量小文件，这种方式有时能进一步减少体积。

代价是提取某一个文件时，可能需要处理同一固实块中的前面内容；频繁修改包内文件也可能更费时间。

普通用户保留默认设置即可。经常随机提取少量文件时，再考虑减小固实块或关闭固实压缩，用一些体积换取操作便利。

### 十、可选：用PowerShell执行常用操作

右键菜单已经能满足大多数需要。如果经常重复处理同一类文件，可以使用随安装程序提供的 `7z.exe`。

下面假设软件安装在默认目录，资料位于 `D:\资料\项目资料`。使用前替换成自己的实际路径，并确保输出目录存在。

#### 1.创建一个7z压缩包

```powershell
& "C:\Program Files\7-Zip\7z.exe" a "D:\资料\项目资料归档.7z" "D:\资料\项目资料\"
```

`a` 表示添加到压缩包。这里会打包所选文件夹及其子目录，不需要为了包含子文件夹额外添加 `-r`。

输出压缩包放在源文件夹外，便于区分。如果同名压缩包已经存在，`a` 会执行添加或更新；希望每次得到独立归档时，应使用新的文件名。

#### 2.保留目录结构解压

```powershell
& "C:\Program Files\7-Zip\7z.exe" x "D:\资料\项目资料归档.7z" "-oD:\资料\解压结果"
```

`x` 表示按原有目录结构提取，`-o` 指定输出目录，参数与路径之间不加空格。PowerShell 中开头的 `&` 用于执行引号里的程序路径。

另一个命令 `e` 会提取文件而不保留目录结构，容易让原本分散在不同子目录中的同名文件发生冲突，日常优先使用 `x`。

#### 3.检查压缩包

```powershell
& "C:\Program Files\7-Zip\7z.exe" t "D:\资料\项目资料归档.7z"
```

`t` 对应图形界面的“测试”。执行后查看输出信息；编写脚本时，还可以通过 PowerShell 的 `$LASTEXITCODE` 判断结果，`0` 表示正常结束，其他值需要进一步检查。

刚开始使用时保留交互提示即可。密码设置优先使用图形界面，避免把明文密码写进可反复查看的命令历史。

### 十一、常见问题

| 问题                     | 可以怎样处理                                                        |
| ------------------------ | ------------------------------------------------------------------- |
| 安装后右键没有7-Zip      | Windows 11 先检查“显示更多选项”，再查看软件的外壳集成设置           |
| 双击仍由其他软件打开     | 调整该扩展名的默认应用，或通过右键选择7-Zip                         |
| RAR无法打开              | 先更新7-Zip，并检查文件是否完整、分卷是否齐全                       |
| 提示CRC错误或数据错误    | 检查下载是否损坏；加密包还要核对密码，不能只凭错误名称确定原因      |
| 提示无法作为压缩包打开   | 检查文件来源、实际格式和下载完成情况，不要只修改扩展名              |
| 密码看起来正确却无法解压 | 检查大小写、复制时的空格，再排查文件损坏或加密方式兼容性            |
| 提示磁盘空间不足         | 检查解压后的体积和目标磁盘空间；拖拽提取时还可能占用临时目录        |
| 压缩后几乎没有变小       | 视频、照片或已有压缩包通常已压缩，属于常见情况                      |
| 分卷只下载了一部分       | 补齐所有分卷，保持名称一致，再从第一卷提取                          |
| 压缩时提示文件被占用     | 保存并关闭相关程序后重试，检查结果中是否有文件被跳过                |
| 文件名出现乱码           | 可能与旧ZIP的文件名编码有关，优先请发送方重新打包，或使用原工具核对 |

遇到错误时，先保留原始压缩包，再尝试重新下载或请发送方重发。7-Zip 的“测试”用于检查问题，不是保证修复损坏文件的按钮。

### 十二、推荐结语与官方地址

7-Zip 适合作为 Windows 上长期保留的小工具：平时用右键菜单解压资料，需要时再使用密码、分卷、测试和命令行功能。

第一次使用，只要记住三个习惯就够了：**解压优先放进独立文件夹，给别人发送普通资料优先使用ZIP，自己归档或需要隐藏文件名时考虑7z。**
