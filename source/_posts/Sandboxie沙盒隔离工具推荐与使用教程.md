### 一、Sandboxie能做什么

试用一个 Windows 小工具，常常不只是打开、关闭这么简单：安装程序可能写入注册表，运行后会留下配置、缓存和临时文件。想把这些变化集中管理，可以使用 [Sandboxie](https://github.com/sandboxie-plus/Sandboxie)。

Sandboxie 会让程序在一个受隔离的环境中运行，这个环境就叫“沙盒”。在默认隔离规则下，程序对文件和注册表的写入会被重定向到沙盒存储中；试用结束后，可以先取出需要的文件，再清理沙盒内容。

它适合临时试用软件、分开管理程序环境，以及观察程序产生的文件。与完整虚拟机相比，它不需要另外安装一套操作系统，程序仍运行在当前 Windows 中。

本文以 **Sandboxie-Plus 1.18.8** 的中文界面为例，按照四张实际操作截图，完成“创建沙盒 → 启动 Notepad++ → 查看进程 → 恢复文本文件”的基础流程，再介绍结束试用后的清理方式。

### 二、下载与安装

#### 1.优先选择Plus稳定版

官方提供 Plus 和 Classic 两种版本，两者共享核心隔离组件，主要区别在于管理界面和新功能的图形化入口。

| 版本              | 界面特点                               | 选择建议               |
| ----------------- | -------------------------------------- | ---------------------- |
| Sandboxie-Plus    | 使用 Qt 界面，持续增加新功能的管理入口 | 初次使用优先选择       |
| Sandboxie-Classic | 使用传统管理界面                       | 适合熟悉旧版操作的用户 |

进入[官方下载页](https://sandboxie-plus.com/downloads/)或 [GitHub Releases](https://github.com/sandboxie-plus/Sandboxie/releases)，选择稳定版安装包。以截图中的版本为例：

| 安装包                             | 对应设备                                           |
| ---------------------------------- | -------------------------------------------------- |
| `Sandboxie-Plus-x64-v1.18.8.exe`   | 大多数使用 Intel、AMD 处理器的 64 位 Windows 电脑  |
| `Sandboxie-Plus-ARM64-v1.18.8.exe` | 使用 ARM 处理器的 Windows 设备，需另行核对授权条件 |

不确定时，在 Windows“设置 → 系统 → 系统信息”中查看“系统类型”。发布页中的 `Source code` 是源码归档，不是安装程序；旧的 32 位版本则在下载页的 Legacy 区域单独列出。

#### 2.完成安装并打开管理器

1. 运行与系统架构匹配的安装包，按向导选择安装位置。
2. 安装驱动和服务时，按 Windows 提示确认管理员权限。
3. 启动 `Sandboxie-Plus`，完成首次使用向导。
4. 如出现软件兼容性检测，阅读检测结果，按需要应用兼容模板。
5. 进入主界面，查看已有沙盒，也可以按下一节新建一个测试环境。

Sandboxie 的程序隔离依赖驱动和服务，即使使用安装程序提供的便携提取方式，也不能理解为在任意电脑上都能免权限运行。

本文使用标准沙盒演示个人基础用法。安全强化、数据保护、加密等选项，以及企业、教育和 ARM64 使用场景，应结合官方[功能与授权对照表](https://sandboxie-plus.com/feature-comparison/)选择。

### 三、创建第一个标准沙盒

先建立一个专门用于试用的沙盒，后面的程序和文件都放进这个环境，方便统一查看和清理。

1. 在主界面左上角点击“新建沙盒”。
2. 在“输入沙盒名称”中填写 `demo_box`，与图 1 保持一致。
3. 选择黄色图标旁的“标准沙盒”。
4. 保持“加密沙盒内容并启用保密功能”和“高级选项”未勾选。
5. 点击右下角“下一步”，核对摘要后点击“完成”。

![新建沙盒向导中输入demo_box并选择标准沙盒](../Sandboxie沙盒隔离工具推荐与使用教程/create-standard-box.png)

_图 1：名称填写为 `demo_box`，已选中“标准沙盒”；下方的加密与高级选项均未开启。_

图 1 上方列出了安全强化、数据保护等不同类型。第一次使用先选标准沙盒，熟悉文件保存、恢复和清理，再按实际需求研究其他类型。

创建后，本文截图中的主界面将这个沙盒显示为 **“demo box”**，即把名称中的下划线显示为空格；后面的运行和恢复窗口对应的都是这个测试沙盒。

一个沙盒可以运行多个程序，这些程序通常共享该沙盒内的文件和配置环境。若要把两组试用环境分开，应创建不同沙盒。

### 四、在沙盒中启动Notepad++

这里使用已经安装的 Notepad++ 演示。它既容易识别运行状态，也方便新建文本来理解文件隔离；也可以换成自己已有的简单文本编辑器。

#### 1.选择程序并启动

1. 在主界面右键点击“demo box”。
2. 选择“运行 → 运行程序（Run）”。
3. 在弹出的“在沙盒中运行”窗口中，点击“浏览”选择 `notepad++.exe`，或输入完整路径。
4. 保持“以 UAC 管理员身份运行”未勾选。
5. 点击“确定”，启动编辑器。

![在demo_box中运行Notepad++的程序路径与启动选项](../Sandboxie沙盒隔离工具推荐与使用教程/run-program.png)

_图 2：窗口标题标明目标为 `demo_box`；输入框只有 Notepad++ 的程序路径，未附加启动参数，也未勾选管理员身份运行。_

图中的填写内容为：

```text
"D:\Program Files\Notepad++\notepad++.exe"
```

使用时应替换为自己电脑上的实际安装路径。这里的双引号用于包围含空格的路径，直接通过“浏览”选择程序更不容易填错。

#### 2.把同样的方法用于其他程序

想试用其他工具，可以在相同窗口选择对应的 EXE；想测试安装过程，则选择可信来源的安装包，在沙盒内完成安装，再从该沙盒的运行菜单启动安装后的程序。

需要内核驱动、复杂系统服务或反作弊组件的软件可能无法正常运行。遇到兼容性问题，先查看主界面的沙盒消息和官方说明，不要为了启动程序而随意放开隔离规则。

### 五、查看进程，确认程序进入沙盒

编辑器打开后，返回 Sandboxie-Plus 主界面，展开“demo box”。**程序是否出现在目标沙盒下，是确认启动位置的直接依据。**

![demo box下的Notepad++进程、辅助进程及运行状态](../Sandboxie沙盒隔离工具推荐与使用教程/sandbox-processes.png)

_图 3：展开“demo box”后，可以看到 `notepad++.exe` 和两个辅助进程；底部状态栏显示共有 3 个沙盒，其中 1 个活跃，当前有 3 个进程。_

对照图 3，可以这样阅读列表：

| 图中项目                                        | 含义                                             |
| ----------------------------------------------- | ------------------------------------------------ |
| `notepad++.exe`                                 | 本次启动的编辑器，位于“demo box”下               |
| `SandboxieRpcSs.exe`、`SandboxieDcomLaunch.exe` | 本次沙盒运行所用的辅助进程                       |
| “进程 ID”列                                     | 区分不同进程的编号，每次运行可能变化             |
| “标题”列中的 `[#] 新文件 1`                     | 编辑器当前窗口的标题，其中带有沙盒标记           |
| “New Box”和“DefaultBox”旁的“空”                 | 图中这两个沙盒没有存放内容，与“demo box”分开显示 |

图中的内存、CPU 和进程编号只表示截图时的状态，不需要与自己的电脑完全一致。重点是确认 `notepad++.exe` 归属于正确的沙盒，并处于运行状态。

如果软件打开了，却没有出现在目标沙盒下，可能是启动请求交给了宿主上已运行的实例。可以先保存并退出旧实例，再从沙盒启动；对于支持独立实例参数的软件，也可按其文档设置。

### 六、保存测试文本并恢复到沙盒外

#### 1.在沙盒内新建测试文本

1. 回到刚才启动的 Notepad++，新建文档并输入几行测试文字。
2. 使用“另存为”，选择桌面，文件名填写 `demo_text.txt`。
3. 保存后留意是否出现文件恢复窗口；如果没有，可以右键“demo box”，选择“文件恢复”。
4. 在恢复前，从沙盒外查看真实桌面，并通过目标沙盒的“沙盒内容”浏览入口检查文件。

默认隔离规则下，编辑器看到的桌面保存位置会被映射到沙盒存储中。也就是说，**在沙盒里点击“保存”，不等于文件已经出现在真实桌面上。** 用户目录下的桌面、文档等内容通常映射到沙盒的 `user\current` 分支，具体位置可通过浏览入口确认。

#### 2.读懂恢复窗口中的路径

![demo box文件恢复窗口中选中的9B文本demo_text.txt](../Sandboxie沙盒隔离工具推荐与使用教程/file-recovery.png)

_图 4：恢复窗口已选中 `demo_text.txt`，显示大小为 9 B、路径为 `C:\Users\<username>\Desktop\demo_text.txt`，下方“恢复目标位置”保持为“原始位置”。_

图中的 `<username>` 是演示账户，自己的用户名可能不同。“完整路径”列展示的是文件对应的正常使用位置，不能仅凭这里显示了桌面路径，就判断它已经位于沙盒外。

窗口左下角显示“有 1 个新文件可供恢复”，说明列表中已有待恢复内容。9 B 是截图里这个测试文件的大小，自己输入不同文字后，大小也会变化。

#### 3.将文件恢复到真实目录

1. 保存文档，最好先关闭仍在编辑它的程序，避免恢复后编辑器继续操作原来的沙盒副本。
2. 在恢复列表中选中 `demo_text.txt`，如图 4 的蓝色行所示。
3. 如果希望文件出现在真实桌面上，保留“恢复目标位置”为“原始位置”。
4. 如需保存到其他目录，展开目标位置下拉框，使用“浏览位置”选择文件夹。
5. 点击右侧“恢复”，完成后从沙盒外打开目标文件，检查内容。

这里的“恢复”是把选定文件从沙盒存储移到外部目录，并不是找回误删文件。图 4 展示的是**点击恢复前的待处理状态**，恢复结果需要到目标目录确认。

若没有看到需要的文件，可以先点击图中的“刷新”，再检查“显示所有文件”，或通过“添加文件夹”纳入实际保存目录。自动提示和快速恢复都有相应的检测、扫描范围，不是每个目录中的文件都会自动弹出通知。

遇到同名文件时，先核对目标内容，再决定是否覆盖。图中上方的“删除”会删除所选文件，不能把它当成恢复后的关闭按钮；暂时不处理时，使用右下角“关闭”。

### 七、结束试用后清理沙盒

文件取出后，再处理沙盒里不需要保留的软件、缓存和配置。关闭编辑器只会结束程序，通常不会自动清除这些内容。

| 操作         | 作用                                             | 使用场景                       |
| ------------ | ------------------------------------------------ | ------------------------------ |
| 终止所有程序 | 结束所选沙盒中的程序，不删除已有文件             | 程序卡住，或清理前仍有进程运行 |
| 删除内容     | 清理沙盒内的文件和隔离注册表等数据，保留沙盒定义 | 本轮试用结束，之后继续复用沙盒 |
| 移除沙盒     | 移除沙盒定义，并按对话框处理存储内容             | 不再使用这个沙盒               |

日常结束试用，可以按下面的顺序操作：

1. 保存工作，正常关闭“demo box”中的程序。
2. 按上一节恢复需要保留的文件，确认在沙盒外能够打开。
3. 在主界面右键“demo box”，选择“删除内容”。
4. 核对对话框中的沙盒名称和待处理内容，确认后执行清理。
5. 等待完成，再查看沙盒状态和内容。

**清理会丢弃仍留在盒中的文档、软件安装结果和设置。** 长期使用的环境不必每次清空；临时试用环境则适合在取出文件后清理，供下一轮测试使用。

### 八、基础使用中容易忽略的边界

标准沙盒主要隔离写入，通常仍允许读取原有文件，也不会自动禁止联网。它不能直接等同于隐藏个人资料、匿名上网或完全独立的虚拟机。

恢复到外部目录的文件会脱离沙盒存储。尤其是 EXE、脚本和带宏文档，不应因为曾经在沙盒中运行，就认定它们可以安全地在宿主中打开。

初次使用时，沿着本文四张图完成一次文本测试即可：先确认沙盒名称和程序归属，再观察保存与恢复的区别。熟悉这套流程后，再按需求研究资源访问、网络限制或其他沙盒类型。
