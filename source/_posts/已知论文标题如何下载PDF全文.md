已经知道论文标题，想下载 PDF 全文，可以先利用高校图书馆的数据库资源；无法直接下载时，再通过学术资源在线提交文献求助，用邮箱接收下载链接。

### 一、进入自己学校的图书馆

1. 搜索“学校名称 + 图书馆”，进入学校图书馆官网。
2. 找到“数据库导航”“电子资源”或类似入口。
3. 在校内按图书馆说明使用校园网访问；在校外，先通过学校提供的 VPN、WebVPN 或校外访问入口完成认证。

下面以[中国地质大学（武汉）图书馆](https://lib.cug.edu.cn/)为例，首页底部可以找到“数据库导航”。实际使用时，应进入自己学校的图书馆。

![高校图书馆首页与数据库导航入口](../已知论文标题如何下载PDF全文/university-library-homepage.png)

学校购买的数据库通常需要识别校园网络或机构身份。从普通搜索结果直接进入出版社网站时，可能只看到摘要或付费入口；遇到这种情况，回到图书馆提供的访问入口重新打开。

### 二、确定论文来自哪个数据库

1. 复制论文的完整标题，在搜索引擎或学术搜索中检索；结果太多时，可给标题加英文双引号。
2. 打开匹配结果，核对标题、作者和发表年份，确认是目标论文。
3. 查看论文的出版社、期刊或会议，以及页面所属网站，确定全文来源。
4. 回到图书馆的数据库导航，找到对应数据库，阅读访问说明后进入。

例如，论文页面位于 **IEEE Xplore**，就找图书馆列表中的 **IEL（IEEE）**；Elsevier 旗下期刊的论文，通常可到 **ScienceDirect** 查找。SCI、EI 等检索库可帮助确认文献信息，全文下载仍需进入相应的全文平台。

![图书馆数据库列表中的IEL（IEEE）与学术资源在线](../已知论文标题如何下载PDF全文/library-database-list.png)

如果完整标题搜不到，可以按以下顺序调整：

1. 去掉复制时带入的换行、多余空格和末尾标点。
2. 去掉双引号，改用标题中较有辨识度的一段文字搜索。
3. 加上第一作者姓名或期刊名称，缩小结果范围。

如果已找到论文的 **DOI**，也可以用它继续检索。DOI 是文献的持久标识符，可帮助区分标题相近的文章；将其接在 `https://doi.org/` 后面访问，通常会跳转到论文的出版页面。

### 三、以IEEE为例下载PDF

#### 1.搜索论文标题

1. 从图书馆入口进入 [IEEE Xplore](https://ieeexplore.ieee.org/)。
2. 在搜索框中粘贴完整标题，点击搜索。
3. 在结果中找到目标论文，点击标题进入详情页。

示例论文标题为：

```text
Synthetic Aperture Radar Image Change Detection via Siamese Adaptive Fusion Network
```

#### 2.进入PDF阅读界面并保存

1. 核对详情页中的标题和作者。
2. 点击标题下方的红色 **PDF** 按钮，进入 PDF 阅读界面。
3. 点击阅读器工具栏中的下载图标，选择保存位置；如果直接弹出下载窗口，保存文件即可。
4. 打开下载的 PDF，确认标题一致、正文完整。

![IEEE论文详情页中的PDF按钮](../已知论文标题如何下载PDF全文/paper-homepage.png)

页面顶部的 **Access provided by** 表示已识别到机构访问身份，但可下载范围仍取决于学校的订购内容。示例论文标有 **Open Access（开放获取）**，可直接获取全文，无需依赖学校订阅。

#### 3.提示购买或无权限时怎么办

1. 查看页面是否显示学校名称，确认当前访问已识别机构身份。
2. 回到图书馆的数据库介绍页，查看订购范围是否包含目标期刊或会议，以及论文发表年份。
3. 如果在校外，确认学校提供的远程访问连接仍然有效，再从图书馆入口打开论文。
4. 认证正常但仍无全文权限时，查看图书馆是否提供其他全文来源；仍无法获取的，再提交文献求助。

登录 IEEE 个人账号与获得学校订阅权限是两回事。个人账号登录成功，并不代表所有论文都能下载。

### 四、通过学术资源在线求助

#### 1.检索论文并提交求助

1. 回到图书馆数据库列表，找到 **SpiScholar 学术资源在线**，按学校提供的入口进入。截图中的平台标识为“SPIS 学术资源在线”。
2. 在学术检索框中输入完整论文标题，找到匹配结果。
3. 查看结果中的全文获取选项；不能直接获取时，点击 **文献求助**。
4. 在弹窗中核对论文标题，填写能正常收信的邮箱。
5. 阅读并同意“文献求助服务条款”，点击 **确定** 提交。

![学术资源在线的文献求助窗口](../已知论文标题如何下载PDF全文/paper-help-find.png)

提交前再核对一次邮箱，尤其注意字母、数字和邮箱后缀。求助依赖平台能否找到全文，提交成功不等于已经获取到文件；处理结果需要等待通知。

#### 2.到邮箱接收下载链接

1. 提交后等待平台处理，留意所填邮箱的来信。
2. 求助成功后，打开文献互助通知邮件，核对论文标题。
3. 点击邮件中的 **点击下载**，按页面提示下载全文。
4. 如果按钮无法打开，可复制邮件中提供的下载地址到浏览器访问。

![文献求助成功后收到的下载通知](../已知论文标题如何下载PDF全文/email-receive-paper.png)

下载链接可能有有效期，收到后应及时保存。建议用“年份 + 第一作者 + 简短标题”命名文件，或导入 Zotero 等文献管理工具，方便后续阅读和引用。

#### 3.未收到邮件或求助失败

1. 查看垃圾邮件文件夹，并在邮箱中搜索论文标题或“文献互助”。
2. 核对提交时填写的邮箱；若填写有误，改正后重新提交。
3. 如果平台明确提示求助失败，查看失败原因，再联系本校图书馆咨询文献传递服务。

咨询图书馆时，提供完整标题、作者、发表年份、期刊或会议名称，以及已有的 DOI 或论文链接，便于工作人员定位文献。
